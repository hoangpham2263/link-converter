TênAffiliate ID

Công cụ hoạt động như thế nào?
  1. Mỗi tài khoản gồm tên (duy nhất) và Affiliate ID Shopee. Tên tạo ra link riêng dạng hoangpham.is-a.dev/link-converter/ten-tai-khoan.
  2. Gửi link đó cho bạn bè. Họ dán link sản phẩm Shopee (nhiều dòng cũng được) và nhận link đã gắn đúng Affiliate ID của tài khoản.
  3. Link gốc được làm sạch: gỡ link affiliate cũ, bỏ tham số theo dõi, chỉ giữ thông tin phân loại sản phẩm.

Lưu ý: link rút gọn (s.shopee.vn/…, shp.ee/…) cần mở ra trên trình duyệt để lấy link sản phẩm đầy đủ rồi mới dán vào, vì trang này chạy hoàn toàn trên máy bạn và không gọi máy chủ. Link tạo ra có dạng s.shopee.vn/an_redir?origin_link=…&affiliate_id=….
